# Customer Churn Intelligence

An interactive machine-learning portfolio project that explores customer churn using a reproducible **synthetic dataset** and a Random Forest classifier. The Streamlit app includes dataset exploration, model metrics, and an interactive prediction form.

> **Important:** The included data is generated by code for demonstration. It is not a real telecom dataset. Model scores are measurements on this synthetic data and must not be represented as real-world business performance.

## Features

- Reproducible synthetic customer dataset (5,000 rows by default)
- Data exploration and churn distribution visualizations
- Random Forest classification with preprocessing pipeline
- Accuracy and ROC-AUC evaluation on a held-out test set
- Interactive customer churn probability estimate
- Unit tests for data generation and inference

## Tech stack

Python, Pandas, NumPy, scikit-learn, Streamlit, Plotly, pytest.

## Run locally (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

If PowerShell blocks activation, run the commands below instead:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## Run tests

```powershell
pytest -q
```

## Methodology

1. Generate synthetic customer attributes using a fixed random seed.
2. Split features and target into stratified training and test sets.
3. One-hot encode categorical fields and pass numeric fields through.
4. Train a Random Forest classifier.
5. Report accuracy and ROC-AUC on the held-out test set.
6. Use the trained pipeline to estimate churn probability for user-entered values.

## Responsible use

This is an educational demonstration. The synthetic labels are generated from an illustrative formula, so the model learns patterns deliberately embedded in that formula. Do not use its predictions to make decisions about real customers.
